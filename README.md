# 🧱 俄罗斯方块 (Tetris)

经典俄罗斯方块游戏，纯 HTML/CSS/JS 实现，双击即玩。

## 快速开始

```bash
git clone https://github.com/zadams123123-ux/-.git
```

直接用浏览器打开 `tetris.html` 即可，无需安装任何依赖。

---

## 🎮 操作方式

| 按键 | 功能 |
|------|------|
| ← → | 左右移动 |
| ↑ | 顺时针旋转 |
| ↓ | 软降（加速下落） |
| 空格 | 硬降（直接落底） |
| P | 暂停 / 继续 |

游戏结束后按 **回车** 或 **空格** 即可重新开始。

---

## ✨ 功能特性

- **7 种标准方块** — I、J、L、O、S、T、Z，袋式随机保证公平分布
- **幽灵投影** — 半透明显示方块最终落点，方便预判
- **等级系统** — 每消除 10 行升一级，下落速度逐渐加快
- **计分规则** — 单消 100、双消 300、三消 500、四消 800，分数 × 当前等级
- **踢墙旋转** — SRS 风格的基础踢墙，旋转时自动尝试左右偏移
- **下一个预览** — 侧边栏实时显示即将到来的方块
- **暂停功能** — 随时暂停，回来后继续

---

## 🎨 界面

深色赛博风配色，每个方块带高光和阴影模拟 3D 质感。侧边栏显示分数、消行数、等级和下一个方块预览。
